# GTAiVoiceCall

Голосовые консультанты на OpenAI **GPT-Live** (`gpt-live-1`): разговаривают с посетителем
сайта в браузере и **сами звонят клиентам по телефону** через вашу SIP-АТС. Модель слушает
и говорит одновременно (полный дуплекс), факты берёт у бэкенд-модели и не прерывает разговор.

Особенность: OpenAI недоступен с российских адресов, а российская телефония не пускает
иностранные — поэтому решение стоит на двух серверах и соединяет их одним защищённым WebSocket.

```
[Клиент] ←PSTN→ [Ваша АТС] ←SIP/RTP A-law→ [Сервер телефонии, РФ: Asterisk + dialer.py]
                                                     ↕ wss://…/pbx/bridge (токен + белый список IP)
                                            [Сервер модели, вне РФ: server.mjs + lib/calls.mjs]
                                                     ↕ wss://api.openai.com/v1/live/sessions
                                                [gpt-live-1 + бэкенд-модель + профиль]
```

## Что умеет

Интерфейс — три линии: **Разговор** (просто поговорить), **С промптом** (роль в поле промпта,
«Основа» из готового профиля, файлы-инструкции txt/md/csv/json/pdf/docx/html — в базу знаний),
**Телефония** (то же плюс список «номер имя», агент звонит по очереди, статусы, транскрипт
и звук текущего звонка в реальном времени).

- **Профили** — один файл в `profiles/` = один консультант: манера речи, сценарий, база знаний,
  голос. Правки видны без перезапуска. Примеры: консультант по продукту, звонок-подтверждение.
- **Браузер** — WebRTC, микрофон, транскрипт и полоса дуплекса (видно, когда говорят одновременно).
- **Телефон** — номер + имя клиента → звонок через АТС; транскрипт и звук разговора оператору
  в реальном времени; запись по флагу.
- **Логи** — каждое событие каждого звонка на обеих сторонах, сводки, CDR, `npm run calls`.
- **Безопасность по умолчанию** — SIP/RTP только с адреса АТС, мост по токену и белому списку,
  список разрешённых номеров, ARI на localhost.

## Быстрый старт

Самый простой путь — отдать `SETUP-AGENT.md` ИИ-агенту (Claude Code, Codex и т.п.): он опросит
вас и развернёт всё сам. Вручную:

```bash
git clone https://github.com/kpshinnik/gpt_voice_pbx.git && cd gpt_voice_pbx
cp .env.example .env && $EDITOR .env    # ключ OpenAI, два SSH-адреса, АТС, домен моста
npm install && npm run check            # проверка доступа к gpt-live-1
bash model-server/deploy.sh             # сервер модели (вне РФ)
bash pbx-server/deploy.sh               # сервер телефонии (в РФ): Asterisk, диалер, nginx, TLS, ufw
ssh -L 3000:127.0.0.1:3000 <MODEL_SSH>  # интерфейс: http://localhost:3000
```

Для локальных экспериментов сервером модели может быть ваш ноутбук вне РФ: `npm start`.

## Требования

- Аккаунт OpenAI с доступом к `gpt-live-1` (голос $0.05/мин посекундно) и модели бэкенда.
- SIP-АТС с внутренними номерами и исходящей связью (проверено на onlinePBX).
- Сервер вне РФ (1 vCPU / 1 ГБ) и сервер в РФ (2 vCPU / 2 ГБ, Ubuntu 22.04/24.04, публичный IP,
  домен с A-записью). Node 20+ локально.
