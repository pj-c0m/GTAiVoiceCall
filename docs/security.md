# Безопасность

Сервер телефонии — самое уязвимое место: Asterisk с открытым SIP исторически становится
источником toll-fraud (кто-то звонит за ваш счёт). Поэтому:

## Сервер телефонии

- **SIP 5060/udp и RTP 10000–10200/udp открыты только для адреса АТС** (ufw). Никаких «Anywhere».
- Asterisk: нет анонимных и гостевых endpoint'ов; входящие от АТС на добавочный отбиваются
  диалпланом; набрать наружу может только ARI-приложение с localhost.
- ARI слушает `127.0.0.1:8088` под паролем из `.env`; AMI выключен.
- Диалер работает от непривилегированного пользователя `gptvoice`, systemd-hardening
  (`ProtectSystem=strict`, `NoNewPrivileges`), логи в `/var/log/gpt-voice`.
- Мост `/pbx/` в nginx: белый список адресов (`BRIDGE_ALLOW`) → затем токен (`BRIDGE_TOKEN`).
  Проверка: чужой адрес → 403, свой без токена → 401.
- `ALLOWED_NUMBERS`: пока `none` — звонить можно только на `test:sim1`; список — только на эти
  номера; пусто — любые. `MAX_CALLS` ограничивает одновременные звонки.
- Deploy не удаляет чужие правила файрвола, но печатает широкие правила для SIP/RTP — уберите их.

## Сервер модели

- Ключ OpenAI и `.env` — только здесь, `chmod 600`. Сервис от `gptvoice`, `HOST=127.0.0.1`.
- Интерфейс оператора не публикуется: SSH-туннель. Если нужен домен — nginx с basic auth.
- Браузерные сессии ограничены `ALLOWED_ORIGINS` и лимитами в час.

## Внешние зависимости при деплое

- `ifconfig.me` — для определения публичных адресов серверов. Не хотите — впишите `BRIDGE_ALLOW` вручную,
  а `PUBLIC_IP` в `pbx-server/deploy.sh` замените на известный адрес.

## Правовое (РФ)

- Деловые звонки маркируются через оператора номера; автоматические вызовы — с согласия абонента.
- Запись разговора (`RECORD_CALLS=on`) требует уведомить собеседника.

## Чек-лист перед запуском

- [ ] `ufw status`: SIP/RTP только с IP АТС, 22/80/443 — и всё
- [ ] `pjsip show registrations` → Registered; `pjsip show endpoints` — только `obpx_endpoint`
- [ ] `curl https://<домен>/pbx/health` → 403 с чужого адреса, 401 без токена
- [ ] `ALLOWED_NUMBERS` задан
- [ ] `.env` не в git (`.gitignore`), права 600 на серверах
