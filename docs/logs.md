# Логи

| Сторона | Файл | Что внутри |
|---|---|---|
| модель | `logs/brain.log` | старт сервера, мост подключён/отключён (код, причина, повтор), Live-сокет по каждому звонку, старт звонка (кому, имя, профиль, голос), сводка, браузерные сессии |
| модель | `logs/calls/<id>.jsonl` | все события звонка с таймстампами: `call.state`, транскрипт-дельты с `start_ms`/`end_ms`, `session.*`, `response.event`, ошибки |
| модель | `logs/calls/<id>.txt` | сводка + расшифровка с таймкодами |
| модель | `logs/calls.jsonl` | индекс всех разговоров (телефон и браузер): `npm run calls`, `npm run calls -- --id <id>` |
| модель | `logs/recordings/` | сюда складывайте записи (`scp` из `/var/spool/asterisk/recording/`) |
| телефония | `/var/log/gpt-voice/dialer.log` | подключения мозга (IP, код закрытия), команды, все события Asterisk по звонку, «ответили через N с», звук каждые 10 с, итог |
| телефония | `/var/log/gpt-voice/calls.jsonl` | `dialer_started`, `brain_connected`, `dial`, `answered`, `audio`, `recording`, `ended`, `rejected`, `ari_lost` |
| телефония | `/var/log/asterisk/full` | SIP-диалоги и регистрация (verbose 3); `asterisk -rx "pjsip set logger on"` добавляет полные SIP-пакеты |
| телефония | `/var/log/asterisk/cdr-csv/Master.csv` | CDR каждого канала |
| телефония | `journalctl -u gpt-voice-dialer -f` | то же, что `dialer.log`, в реальном времени |

## Как разбирать

- **Не слышно абонента** — в `dialer.log` строки `звук — из АТС N кадров`: если `N` не растёт,
  RTP от АТС не доходит (файрвол, адрес АТС изменился).
- **Абонент не слышит робота** — `в АТС M (речь K)`: если `K` не растёт при говорящей модели,
  проблема между мозгом и мостом; если растёт — между Asterisk и АТС (кодек, NAT).
- **Звонок не проходит** — `pjsip set logger on`, повторить, смотреть в `full` ответ на INVITE:
  `404` — формат номера или нет правила исходящих; `403` — запрет; `486` — занято; `480` — не отвечает.
- **Мост рвётся** — `brain.log`: `мост: отключён {code, reason}`; `dialer.log`: `мозг отключился … код`.
- **Стоимость** — `usage_seconds` и `cost_usd` в `calls.jsonl` (голос), делегирования бэкенда — отдельно.
