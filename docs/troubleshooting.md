# Что может пойти не так

Таблица из `SETUP-AGENT.md`, вынесена отдельно.

| Симптом | Причина | Лечение |
|---|---|---|
| `Registered`, но звонок обрывается через 0,5 с; в SIP-трассе `407 → 183 → 404` | АТС не приняла формат номера (onlinePBX: `8…` → 404, `7…` → OK) или добавочному запрещены исходящие | `DIAL_PREFIX`; правило исходящих в АТС |
| `Rejected` при регистрации | неверный пароль/добавочный или АТС не пускает с этого IP | проверить `.env`; спросить поддержку АТС |
| Endpoint `Unavailable` | `qualify` при АТС, не отвечающей на OPTIONS | в шаблоне qualify нет |
| ARI `record → 500` | нет `/var/spool/asterisk/recording` | deploy создаёт; права `asterisk` |
| Мост `403` для сервера модели | адрес не в `BRIDGE_ALLOW` (часто: IPv4 против IPv6) | оба адреса, редеплой |
| `1006` после деплоя | перезапуск диалера | норма |
| `1002` на старте звонка | protocol error на мосту | `reason` в `brain.log`, `ошибка сокета` в `dialer.log`; повторить |
| Одна сторона не слышна | RTP/файрвол или мозг↔мост | счётчики в `dialer.log` (см. `docs/logs.md`) |
| Пустой wav самопроверки | MixMonitor на Local | используется ARI-запись моста |
| `401/403` от OpenAI | ключ/доступ к `gpt-live-1` | `npm run check` |
| «Позвонить» неактивна | мозг не подключён к мосту | статус обновляется каждые 4 с; `brain.log` |
| Названия звучат неправильно | TTS без ударений | «Произношение» в профиле |
| Длинные паузы «сейчас уточню» | факт в базе бэкенда, а не в голосовой модели | перенести в «Что знаешь сама» |
